# Jobs (the careers CMS)

One file = one job. Notes for yourself in `<!-- ... -->` never appear on the site.
The file name is the job address: `brand-designer.md` → `/careers/brand-designer`.

## Add a job
1. Copy any file here and rename it (lowercase words with dashes).
2. Fill the fields at the top, between the two `---` lines:

| Field | What it is |
|---|---|
| `title` | job title (about 25 characters) |
| `order` | position in the list: 1, 2, 3… |
| `type` | e.g. `Full-time`, `Part-time` |
| `salary` | e.g. `$90,000 – $120,000 per year` |
| `location` | e.g. `Remote`, `Dubai, UAE` |
| `about` | 2–3 sentences about the role (shown in the list and on the job page) |

3. Write the job text below the fields:
   - `### ` section heading (Responsibilities, Qualifications, Benefits…)
   - `- ` list item
   - empty line between paragraphs

Remove a job: delete its file. The careers page lists every file here.
