# Legal documents

One file = one document. The file name is the address: `privacy-policy.md` → `/legal/privacy-policy`.
The footer, the menu and the forms link to `privacy-policy` and `terms-of-service`; keep those names.

Fields at the top, between the two `---` lines:

| Field | What it is |
|---|---|
| `title` | document title |
| `date` | last update, `YYYY-MM-DD` (shown as "Feb 24, 2026") |
| `intro` | the large first paragraph |

Text below: `## ` section heading, empty line between paragraphs, `- ` list item, `[text](address)` link.
Have a lawyer check these texts for your own business: the template texts are examples.
