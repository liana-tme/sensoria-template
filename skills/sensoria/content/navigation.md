# Navigation — what the owner changes

File: `src/sections/navigation/content.ts`. Change only the values there.

- **Logo:** the brand name (`logo.name`) — it is set as text in the serif font, no image.
- **Links:** label + address for the big menu links. Keep 3–6, one or two short words each.
- **Button:** one short action, two or three words. `href` empty = a placeholder that goes nowhere: fill it with a page (`/contact`) or a link. `newTab: true` for links to other sites.
- **Contact:** the line above the e-mail ("Need Support?") and the support e-mail.
- **Legal:** the small links at the bottom (privacy, terms).

Tone: short and calm, no exclamation marks.
