# Concept — what the owner changes

File: `src/sections/concept/content.ts`.

- **Tag:** `[Concept]` style label.
- **Title:** two short, strong words (it is huge: up to 144 px). Longer titles break into more lines and push the button down.
- **Button:** one short action and where it leads (usually the pricing block, `/#pricing`, or a contact page).
- **Photos:** five vivid portraits, any orientation (shown square, centre crop). Order: top-left, bottom-left, centre, top-right, bottom-right; on phones only the first three show. Write an alt text for each. Only the owner's own photos.
