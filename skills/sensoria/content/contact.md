# Contact — what the owner changes

- **Form:** `src/sections/contact/content.ts` — heading (two parts), tag, form-service address in `action` (empty = the visitor's e-mail app writes to `fallbackEmail`), labels, placeholders, the topic list (3–5 short options), button texts, the note and its link, page title and description.
- **Direct contact:** `src/sections/channels/content.ts` — tag, heading, the line, and 2 cards: icon name, title, one sentence, link label and address (`mailto:` for e-mail, a maps link for the address).
