# Journal — what the owner changes

- **Articles:** files in `src/content/journal/` — see the README there (fields, Markdown, photos). Title about 50 characters, intro one or two sentences, 3 sections with `##` headings.
- **List page:** `src/sections/journal-list/content.ts` — heading (two parts), how many cards show first (`pageSize`), the "Load More" label, page title and description for search.
- **Article pages:** `src/sections/article/content.ts` — the tag beside the text, the "More Insights" tag, heading and how many other articles it shows.
- Never invent facts or numbers in an article: ask the owner.
