# About Us — what the owner changes

File: `src/sections/about/content.ts`.

- **Tag:** `[About Us]` style — a short label in square brackets.
- **Heading:** two short parts (2 words each is ideal); the second part is shown softer.
- **Intro:** one sentence about how the product works, framed by two short punchy parts marked `bright`.
- **Card titles and texts:** a 2-word title and one sentence (about 60 characters) per card.
- **Photos (card 1):** 3–5 vivid beauty portraits, any orientation (shown 180×200, centre crop). Write an alt text for each.
- **Chat (card 2):** the assistant's name and a small square avatar, one helpful message (about 75 characters), an input placeholder.
- **Metric (card 3):** the counter range (it counts from `from` to `to`), a short badge, a label. Bars: 4–6 months, a value each and a height from 0 to 1 (1 = the tallest); mark one bar `highlight` (usually the latest).
- All numbers here are examples — replace them with real ones or remove the claim.
